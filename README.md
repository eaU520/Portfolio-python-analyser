## Overview
This is my first Python project for my portfolio to acquire a contract or full-time remote software engineering position. 

## Goals
- Practice basics of Python, including variables, built-in functions, and small functions.
- Work with lists, for loops, and conditional statements.
- Parse CSV files.
- Build familiarity toget to an engineering measurement analysis tool.

## Requirements
- Python 3

## How to Run
In a terminal/command line in the folder of the practice.py, top-level directory

```bash
python practice.py
```

In a terminal/command line in the top-level directory

```bash
python main.py
```
Running tests: In a terminal/command line in the top-level directory

```bash
python -m pytest -v
```
